# Dino Atlas 0.5.0 — zadání nových rekonstrukcí

Osm původních obrázků bylo vytvořeno vestavěným nástrojem imagegen. Finální pracovní obrázky patří do složky images/ a používají formát WebP. Původní PNG zůstávají pracovními výstupy. Zbarvení a měkké tkáně jsou ilustrativní; nejisté znaky vysvětlují popisky v dinosaurs.json. Rekonstrukce slouží k poznávání, nikoli jako přesná fosilní měření. Měřítko velikosti v aplikaci vychází z číselných údajů, ne z velikosti zvířete na obrázku.
